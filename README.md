# Employee Performance & Workforce Analysis

## 📌 Project Overview

This project analyzes an employee dataset using Python and Pandas to understand workforce patterns, salary differences, employee performance, education levels, work modes, and employee status.

The project also includes data cleaning and visualizations to make the analysis easier to understand.

## 🎯 Project Objective

The main objectives of this project are:

* Analyze employee departments and workforce distribution
* Calculate average salaries
* Study the relationship between experience and salary
* Analyze employee performance ratings
* Compare salaries across education levels
* Analyze work modes
* Analyze active and former employees
* Identify missing values, duplicate records, and invalid dates
* Create visualizations to represent important findings

## 📂 Dataset

The dataset contains information about **100 employees** and **10 columns**.

### Columns

* Employee_ID
* Name
* Department
* Education_Level
* Years_of_Experience
* Salary_USD
* Performance_Rating
* Joining_Date
* Work_Mode
* Status

## 🛠️ Technologies Used

* Python
* Pandas
* Matplotlib

## 🔍 Analysis Performed

### 1. Department Analysis

Analyzed the number of employees working in each department.

### 2. Salary Analysis

Calculated:

* Overall average salary
* Average salary by department
* Average salary by education level
* Average salary by performance rating

### 3. Experience Analysis

Analyzed years of experience and salary and calculated the correlation between them.

### 4. Performance Analysis

Analyzed the distribution of employee performance ratings.

### 5. Employee Status Analysis

Analyzed the number of active employees and employees who have left.

### 6. Work Mode Analysis

Analyzed employees working in:

* Hybrid
* On-site
* Remote

### 7. Education Analysis

Analyzed employee education levels and their average salaries.

### 8. Data Cleaning

Checked the dataset for:

* Missing values
* Duplicate rows
* Invalid joining dates

One invalid joining date was identified and converted to a missing date value during cleaning.

## 📊 Key Findings

* The dataset contains **100 employees**.
* The overall average salary is approximately **$90,068**.
* **Data Science** has the highest average salary among the departments in this dataset.
* **Marketing** has the lowest average salary among the departments in this dataset.
* **Hybrid** is the most common work mode, with **63 employees**.
* **93 employees** are active and **7 employees** have left.
* The correlation between experience and salary is approximately **0.395**, showing a moderate positive relationship in this dataset.
* Employees with different education levels show different average salaries in this dataset.

> These findings describe this particular dataset and should not be treated as general conclusions about all employees or companies.
